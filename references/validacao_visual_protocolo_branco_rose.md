# Validação visual — Protocolo Branco/Rosé

Data da verificação: 13/08/2026.

Foi aberta a rota `/protocolos` no ambiente de desenvolvimento. A página apresentou correctamente o protocolo activo **“Branco/Rosé — Entrada e Fermentação”**, aplicável a cubas de vinho, com as sete etapas criadas:

1. Sulfitagem / preparação inicial
2. Enzima / preparação inicial
3. Inoculação de levedura
4. Nutriente inicial
5. Controlo de nutriente intermédio
6. Oxigenação / controlo fermentativo
7. Passagem a limpo

Todas as etapas foram apresentadas como **“Acção inicial — sem leitura”**, conforme o requisito para operações feitas antes de existir uma leitura de densidade. Os botões de edição exigem sessão autenticada, pelo que não são visíveis na sessão pública usada apenas para validação visual.
